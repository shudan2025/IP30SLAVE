# GitLab Deployment

## Status

GitLab runs as `sameersbn/gitlab:19.5.1` with PostgreSQL 17 and Redis 7 in `deploy/gitlab/compose.yaml`. The server-side project and root-only `.env` are under `/opt/ip30slave/gitlab/`.

The public URL is `https://<server-ip>/gitlab` through Caddy, with `GITLAB_RELATIVE_URL_ROOT=/gitlab`. Direct host ports `18080` (HTTP) and `10022` (SSH cloning) remain published; restrict them to trusted networks. PostgreSQL required `max_locks_per_transaction=1024` to complete the initial schema migration.

## Identity and email

GitLab supports direct LLDAP authentication using the unique `mail` attribute and Dex OIDC at `https://<server-ip>/dex`. `preferred_username` maps to `mail`, and `OAUTH_AUTO_LINK_LDAP_USER` links OIDC identities to existing LDAP accounts. Direct LDAP remains enabled as a fallback. The LDAP bind currently uses the LLDAP administrator; replace it with a least-privilege account before production.

GitLab sends mail through `mailserver:25` without TLS or SMTP authentication on the private `ip30-lldap-mail` network. The GitLab container trusts the Caddy root through its generated CA bundle. This internal mail path is for the isolated candidate only.

The initial GitLab root password is stored on the current server at `/opt/ip30slave/gitlab/gitlab-root-password`, root-only. Do not copy its contents into the repository or deployment logs.

## Deployment

The protected GitLab `.env` contains GitLab secrets, LLDAP bind settings, and Dex OIDC client settings. Validate and start GitLab and its database/cache dependencies with:

```sh
cd /opt/ip30slave/gitlab
sudo docker compose --env-file .env -f compose.yaml config -q
sudo docker compose --env-file .env -f compose.yaml up -d postgresql redis gitlab
```

Dex client configuration is generated by `/opt/ip30slave/dex/render-config.py`; see [dex.md](dex.md). SVN has a separate service directory; see [svn.md](svn.md) for its build/start and authorization steps. The active GitLab, PostgreSQL, and Redis containers use this service-specific Compose file.

## Validation and limits

- The GitLab UI returned HTTP 200 on the direct HTTP port; the SSH clone port accepted TCP connections.
- `gitlab:ldap:check` reported LDAP authentication success and returned an LLDAP directory entry.
- OIDC initiation redirected to Dex with the `/gitlab/.../callback` URI.
- A GitLab Rails test email was delivered to the local postmaster mailbox and removed.

No employee credentials were used for an end-to-end sign-in test. Employee devices must trust the Caddy internal root CA. The candidate mailserver has no external DNS/MX or delivery configuration.
